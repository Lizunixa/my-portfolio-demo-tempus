# TEMPUS — Demonstration Watch Store

TEMPUS is a fictional watch-store website created as a demonstration and portfolio project. It showcases a responsive front-end interface and basic shopping-cart interactions.

**This project is a demo, not a real online store.** It is not connected to a payment provider or order-processing system.

## Features

- Responsive layout for desktop and mobile screens
- Product cards and navigation
- Add and remove products from the shopping cart
- Change product quantities in the cart
- Save cart data in the browser using `localStorage`
- Demonstration contact form
- Demonstration checkout modal
- Smooth scrolling and scroll-reveal animations
- Responsive mobile navigation

## Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage API
- Intersection Observer API

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For a more convenient development workflow, open the project folder in Visual Studio Code and use the Live Server extension.

The project can also be published as a static website using GitHub Pages.

## Demo limitations

TEMPUS is provided for demonstration and portfolio purposes only.

- No real products are offered for sale.
- No payments are accepted or processed.
- Orders are not transmitted to a seller or stored in a real order-management system.
- The contact form is demonstrational and does not send messages.
- Do not enter real personal, contact, or payment information.
